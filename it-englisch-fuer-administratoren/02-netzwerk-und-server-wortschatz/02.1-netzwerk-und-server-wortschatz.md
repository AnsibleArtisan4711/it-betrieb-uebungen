## Aufgabe

### Aufgabe 1 – Netzwerkbegriffe (Einheit 2.1)

Ordne zu: (1) default gateway, (2) name resolution, (3) timeout, (4) subnet mask, (5) packet loss, (6) latency, (7) bandwidth, (8) firewall rule, (9) network cable, (10) wireless access point. A Verzögerung B Funknetz-Zugangspunkt C Verlust von Datenpaketen D Regel der Firewall E Übertragungsrate F Standardgateway G Namensauflösung H Zeitüberschreitung I Subnetzmaske J Netzwerkkabel.

### Aufgabe 2 – Betriebsbegriffe (Einheit 2.2)

Schreibe vier Sätze zu dieser Lage: Der Fileserver wird am Sonntag von 22 Uhr bis 24 Uhr gewartet; vorher wird eine Sicherung gemacht; wenn die Wartung scheitert, wird der alte Zustand wiederhergestellt. Benutze mindestens vier Wörter aus: maintenance window, backup, restore, roll back, outage, available.

### Aufgabe 3 – Handlungsanweisungen (Einheit 2.3)

Formuliere auf Englisch fünf kurze Anweisungen im Imperativ: (a) Dienst neu starten. (b) Protokolldatei öffnen. (c) Nicht ausschalten. (d) Zuerst sichern. (e) Rückmeldung geben, wenn fertig. Eine Anweisung soll höflich als Bitte formuliert sein.

## Hinweise

- „Down“ und „offline“ werden nicht immer gleich verwendet.

## Kontrollfragen

1. Was bedeutet „The server is down“?
2. Was ist ein maintenance window?
3. Wie bittest du höflich um Rückmeldung?
