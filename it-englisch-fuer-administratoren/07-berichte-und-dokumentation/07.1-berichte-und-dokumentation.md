## Aufgabe

### Aufgabe 1 – Vorfallsbericht (Einheit 7.1, Einheit 7.3)

Schreibe auf Englisch einen Bericht mit **Summary** (1 Satz), **Timeline** (mindestens 4 Einträge mit Uhrzeit), **Cause** (belegt oder vermutet kennzeichnen), **Actions** (2 Punkte). Daten: 08:36 DNS service stopped, 08:42 first user report, 09:05 service started, 09:06 intranet available again, Ursache unklar.

### Aufgabe 2 – Change-Beschreibung (Einheit 7.2)

Schreibe eine Änderungsbeschreibung mit **Purpose**, **Scope**, **Time window**, **Impact**, **Rollback plan**. Angaben: Update des Dateiservers am Sonntag, 22:00 bis 24:00, Dateizugriff nicht verfügbar, vorher Sicherung, bei Fehlern Rückkehr zum Sicherungsstand.

### Aufgabe 3 – Zeitformen (Einheit 7.3)

Verbessere: (1) The service stops at 08:36 yesterday. (2) We have restart the server at 09:05. (3) Since two hours the problem is open. (4) The update takes 15 minutes. It was finished. (5) Thirty users has been affected.

## Hinweise

- Verwende für abgeschlossene Vorgänge die Vergangenheit (stopped, started).
- Alle Daten sind erfunden.

## Kontrollfragen

1. Was gehört in eine Timeline?
2. Warum trennt der Bericht Ursache und Vermutung?
3. Was ist ein rollback plan?

## Musterlösung

<details>
<summary>Antworten und Zielzustand (erst nach dem Versuch öffnen)</summary>

**Aufgabe 1 (Vorfallsbericht).** Beispiel: Summary: The intranet was unavailable for 24 minutes because the DNS service on SRV01 had stopped. Timeline: 08:36 DNS service stopped. 08:42 First user report. 09:05 DNS service started. 09:06 Intranet available again. Cause: The reason why the service stopped is unknown (not confirmed). Actions: 1. Check the event log for the reason. 2. Add an alert for the DNS service.

**Aufgabe 2 (Change-Beschreibung).** Beispiel: Purpose: Install the monthly update. Scope: File server SRV01. Time window: Sunday, 22:00 to 24:00. Impact: File access is not available during this time. Rollback plan: If the update fails, we restore the backup made at 21:30 and restart the server.

**Aufgabe 3 (Zeitformen).** (1) The service stopped at 08:36 yesterday. (2) We restarted the server at 09:05. (3) The problem has been open for two hours. (4) The update took 15 minutes. It is finished. / It was finished. (5) Thirty users were affected.

**Fragen.** (1) Uhrzeit und Ereignis in zeitlicher Reihenfolge. (2) Damit klar ist, was belegt ist. (3) Plan zur Rückkehr zum vorherigen Zustand.
