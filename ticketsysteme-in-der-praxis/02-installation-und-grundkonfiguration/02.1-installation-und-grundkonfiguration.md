## Aufgabe

### Aufgabe 1 – Paketinstallation (Einheiten 2.1, 2.2)

Installiere Elasticsearch und Zammad nach der offiziellen Dokumentation via `apt`. Reihenfolge laut Zammad-Installationsseite: **zuerst Elasticsearch** (Anleitung von Elastic bzw. Zammad-Tutorial zu Elasticsearch 9), dann `sudo apt install curl apt-transport-https gnupg`, Schlüssel und Paketquellen-Datei für Ubuntu 24.04 aus der Zammad-Dokumentation, `sudo apt update`, `sudo apt install zammad`. PostgreSQL und Nginx werden laut Dokumentation mitinstalliert.

Lade `mailpit-linux-amd64.tar.gz` von den GitHub-Releases, entpacke mit `tar xzf mailpit-linux-amd64.tar.gz mailpit` und installiere mit `sudo install -m 755 mailpit /usr/local/bin/mailpit`. Prüfe mit `mailpit version` (ohne Internet erscheint zusätzlich ein Fehler bei der Update-Suche, die Versionszeile erscheint trotzdem).

### Aufgabe 2 – Web-Setup (Einheit 2.3)

Öffne auf der Client-VM `http://zammad.example.internal`. Durchlaufe den Wizard, lege einen Administrator an (z. B. `admin@example.internal`) und trage als System-URL `http://zammad.example.internal` ein. Überspringe die E-Mail-Konfiguration.

### Aufgabe 3 – Rückbau (Einheit 2.3)

Entferne die zweite Schnittstelle aus Netplan, fahre die VM herunter, entferne den Netzwerkadapter in Hyper-V und starte neu. Prüfe: Zammad vom Client erreichbar, `ip route` ohne Default-Route, `ping -c 3 8.8.8.8` schlägt fehl. Lege dann einen Hyper-V-Checkpoint `nach-Modul-2` der Server-VM an.
