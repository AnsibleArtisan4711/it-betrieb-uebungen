## Lernziele

Nach dieser Übung kannst du

- agentenbasierte und agentenlose Inventarisierung unterscheiden
- einen Agenten auf einem Windows- und einem Linux-Client einrichten
- automatisch erfasste Daten mit dem manuellen Bestand abgleichen

## Voraussetzungen

- Modul 4
- `win-client` und `lx-client` erreichen `asset-srv`

## Grundbegriffe

| Begriff | Bedeutung |
|---|---|
| **Agent** | Programm auf dem Gerät, das Daten an den Server sendet |
| **Agentenlose Erfassung** | Abfrage über das Netzwerk, z. B. SNMP |
| **SNMP** | Protokoll zur Abfrage von Netzwerkgeräten |
| **Netzwerkerkennung** | Suche nach Geräten im Netz |

| Was | Rolle in Modul 05 |

| `win-client` | Windows 11 Evaluation, `192.168.110.20/24`, 4 GB RAM |

## Aufgabe

### Aufgabe 1 – Konzepte (Einheit 5.1)

Vergleiche in einer Tabelle Agent und agentenlose Erfassung (Vorteile, Grenzen, Sicherheit, Netzwerkbedarf). Nenne ein Gerät, das nur agentenlos erfassbar ist (Beispiel: Switch).

### Aufgabe 2 – Agent einrichten (Einheit 5.2)

Richte den GLPI Agent auf `win-client` und `lx-client` ein und sende das Inventar an `asset-srv`. Die Funktion für das Inventar im Server (Plugin „GLPI Inventory“ oder natives Inventar), der URL-Pfad und die Installationsschritte sind in der Dokumentation der verwendeten Version nachzulesen und im Protokoll festzuhalten (*nicht bestätigt*). Prüfe, ob beide Geräte erscheinen.

### Aufgabe 3 – Abgleich (Einheit 5.3)

Vergleiche für beide Geräte Name, Seriennummer und Betriebssystem aus dem Inventar mit dem manuellen Eintrag (falls vorhanden) und dokumentiere Abweichungen mit vermuteter Ursache und Maßnahme.

## Hinweise

- Ein Agent meldet nur, solange das Gerät eingeschaltet und erreichbar ist.
- Entscheide vorab, welcher Datenquelle bei Abweichung vertraut wird.
- Notiere Version des Agenten und des Servers im Protokoll.

## Kontrollfragen

1. Warum erfasst ein Agent nur eingeschaltete Geräte?
2. Welche Sicherheitsfragen stellt die Kommunikation zwischen Agent und Server?
3. Wann sind manuelle Daten die „Wahrheit“, wann das Inventar?

## Musterlösung

<details>
<summary>Antworten und Zielzustand (erst nach dem Versuch öffnen)</summary>

**Aufgabe 1 (Beispiel).**

| | Agent | agentenlos |
|---|---|---|
| Vorteil | detaillierte Daten (Software, Hardware) | keine Installation am Ziel |
| Grenze | nur auf Geräten mit Betriebssystem | weniger Details |
| Sicherheit | Zugangs- und Transportschutz zum Server | Zugangsdaten für Abfrage nötig |

**Aufgabe 3.** Zielzustand: Eine Tabelle listet je Gerät die Abweichung und die Maßnahme (Beispiel: Name im Betriebssystem anders als in der Verwaltung, Maßnahme: Namenskonvention durchsetzen).

**Fragen.** (1) Ausgeschaltete Geräte können nicht senden. (2) Verschlüsselung, Authentifizierung, Berechtigung des Servers. (3) Manuelle Daten gelten für Verantwortung und Status, das Inventar für technische Fakten.
