## Lizenz

Die Lizenz gilt je Kursordner und steht dort in der Datei `LICENSE` (Code) bzw. `LICENSE-DOCS.md` (Texte). Der Hinweis in der README des jeweiligen Kurses nennt, welche Lizenz gilt.
